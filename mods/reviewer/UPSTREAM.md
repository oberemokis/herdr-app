# reviewer

Источник: https://github.com/vytasgavelis/herdr-reviewer, папка `mods/reviewer`, коммит `01e6d108a8fcc6aeaa07df5c068af59bdd642117` (версия 0.6.0). Лицензия MIT, текст в `LICENSE`, сторонние уведомления в `THIRD-PARTY-NOTICES`.

## Что изменено

- Комментарии уходят только агенту Claude Code, чей терминал работает в том же репозитории или worktree, что и просматриваемый дифф (сравнение `git rev-parse --show-toplevel`). Нет такого агента, ничего не отправляется.
- Отправка через `hc send --if idle` или `--if working`, без `--force`: заблокированный агент (диалог разрешения) текст не получает. Перед отправкой агент перепроверяется, не ушёл ли он из worktree.
- Новый агент из панели не запускается.
- Поле коммита убрано (`git add -A` и `git commit`): коммитит агент.
- Квадратные углы: `square.js` обнуляет радиус скругления у всех элементов мода, вызов в `init`.
- Сетка раскладки workbench: шапка 32 вместо 42, кнопки шапки и окна комментария высотой 24 с отступом 8.
- База диффа сначала `origin/<base>`, затем локальная `<base>`: локальная база в основной папке отстаёт.
- База ветки из `git config branch.<ветка>.base` важнее `props.base`; если такой ветки нет ни на origin, ни локально, берётся `props.base`.
