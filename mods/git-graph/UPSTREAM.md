# git-graph

Источник: https://github.com/rabeeh-ta/herdr-git-graph, папка `mods/git-graph`, коммит `0da886243b2e27a6068d6adb7c5c26f349cdc04e` (версия 0.3.3). Лицензия MIT, текст в `LICENSE`.

## Что изменено

- Граф только смотрит: `executeAction` отклоняет всё, кроме Fetch, а меню показывают лишь Fetch, копирование, переход в Changes, ссылку на код-хост и новую вкладку.
- Двойной клик по метке больше не переключает ветку.
- Проверка обновлений на GitHub выключена (`CHECK = false` в `update.js`): копия обновляется руками, сверкой с автором.
- Квадратные углы: `square.js` обнуляет радиус скругления у всех элементов мода, вызов в `init`.
- Сетка раскладки workbench: шапка 32 вместо 42, отступ 14 у шапки, панели фильтров, полосы деталей и правого края таблицы (с ним `labelLimit`), кнопка-иконка 24 × 24, кнопки с подписью высотой 24 с отступом 8.
- Базовая ветка из props блока (`{ "base": "dev" }`) выделена цветом акцента, локальная и удалённая.
- База текущей ветки из `git config branch.<ветка>.base` выделяется вместо неё, если такая ветка есть локально или на origin (читается в `readFolder` вместе с остальным).
