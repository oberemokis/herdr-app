# workbench-footer

Источник: подвал мода `workspace-chrome` (ветка `props.footer`), который поставляется с Herdr.app 0.1.15. Лицензия Apache-2.0, текст в `LICENSE`.

## Что изменено

- Оставлен только подвал сайдбара: Settings и Add machine.
- Settings открывает меню «Herdr» (окно настроек Herdr) и «Over9k» (настройки сайдбара). Встроить раздел в само окно Settings нельзя: это экран Herdr, он переписывается при каждом запуске.
- Иконки берутся из папки `workspace-chrome`, которая есть в любой установке Herdr.
