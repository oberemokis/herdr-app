# over9k

Источник: https://github.com/herunan/herdr-over9k, папка `over9k-sidebar/mods`, коммит `a53c200addf068adfc7cc131cbad32f8fd8fd747`. Лицензия MIT, текст в `LICENSE` каждого мода. Этот файл описывает правки всех модов `over9k*`; исходные клавиши автора лежат в `upstream-keys/` корня репозитория.

## Что изменено

- Handoff убран целиком: мод `over9k-handoff`, `handoff.sh`, пункт меню, переключатели в Options и `syncHelpers`, который копировал скрипты в `~/.local/share/over9k` и вписывал правило в глобальные `CLAUDE.md` и `AGENTS.md`.
- «clear + recap» убран: `exp.` у агента стал пассивной меткой истёкшего кеша.
- Переключатели статус-линий Claude Code и Antigravity убраны вместе с `setup.sh`, `claude-statusline.sh` и `antigravity/`: мод больше ничего не пишет в `~/.claude/settings.json`.
- Самообновление через `git pull` и `install.sh` убрано вместе с карточкой обновления.
- Чтение 200 строк экрана каждого шелла раз в 4 секунды убрано, подпись «последняя команда» больше не показывается. Осталось чтение 8 строк терминала Pi: из него берутся модель и контекст Pi.
- Запросы к GitHub (`gh api`, `gh repo view`, `gh pr list`) и автоматический `git fetch` раз в 5 минут убраны, с ними чипы PR, issues и stars.
- Pull, как и push, требует второго клика за 4 секунды.
- Кнопка стоп убивает процесс только на этой машине: pid с другой машины раньше убивался локально.
- `place` в `mod.json` теперь `none`: сайдбар ставит раскладка.
- Квадратные углы во всех модах `over9k*`: `square.js` обнуляет радиус скругления у элементов мода, вызов в `init`.
- Раздел «Parked» (проекты без открытого пространства) скрыт константой `HIDE_PARKED`; проект открывается через `+`.
- Строка «Over9k help & options» скрыта константой `HIDE_OPTIONS_ROW`: настройки открываются клавишей `mod.open:over9k-options` из `keys.json`.
- Дерево пространств строится по меткам `task-fleet.space` и `task-fleet.parent`, которые ставит `task-fleet` из oberemokis/skills, а не по git. Пространство задачи встаёт под пространство оркестратора, терминалы этого пространства остаются в нём и не уходят в строку папки: сверху сам оркестратор (`task-fleet.parent`), под ним задачи, ниже прочие терминалы. Деревья идут первыми, остальные пространства ниже в прежнем порядке. Worktree, открытый руками, под основной checkout больше не вкладывается. По git связь не работала: оркестратор бывает в пространстве на `~`, а два оркестратора в одном репозитории неразличимы.

Остались без изменений: строки агентов и терминалов, сканеры сессий Claude (читают `~/.claude`, пишут только в `~/.cache/over9k`), меню, переименование, закрытие, переключатель агентов, лаунчер `+`.
