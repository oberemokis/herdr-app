# herdr-app

Моя настройка [Herdr.app](https://herdr.dev) под работу с агентами в git worktree: раскладка `workbench` и моды для неё. Моды взяты у авторов из галереи herdr.dev, лежат здесь копиями и подогнаны под один принцип: панели смотрят, а репозиторий меняет агент.

## Что в раскладке

| Где | Мод | Что показывает |
| --- | --- | --- |
| слева сверху | `machine-vitals` | загрузка CPU, память, диск, батарея |
| слева | `over9k` и его спутники | пространства и агенты: модель, контекст, кеш, сабагенты, фоновые задачи |
| вкладки | `workbench-tabs` | вкладки и кнопки боковых панелей |
| шапка терминала | `workbench-pane` | программа, папка и статус агента; кнопки разделить, развернуть, закрыть |
| панель Files | `better-files` | дерево файлов и просмотр |
| панель Changes | `better-changes` | изменения, stage и unstage, история |
| панель Review | `reviewer` | дифф ветки от базы с комментариями по строкам, которые уходят агенту этого worktree |
| панель GitLab | `gitlab` | MR ветки, пайплайн по стадиям и джобам, логи джоб, задачи |
| панель Graph | `git-graph` | граф веток, база выделена |

Подвала с Settings и Add machine в сайдбаре нет: настройки Herdr открывает `cmd-,`, настройки over9k `cmd-alt-,`, машины добавляются в Settings → Machines.

Тема `opencode` (тёмная) и `opencode-light` (светлая) в `themes/`: палитра темы по умолчанию из [OpenCode](https://github.com/anomalyco/opencode) (`packages/tui/src/theme/assets/opencode.json`, MIT), разложенная по цветам Herdr. Раскладка берёт ту, что соответствует режиму системы. Выбор в меню тем Herdr её перекрывает.

Углы везде прямые: у карточек терминалов радиус 0 в раскладке, а каждый мод при старте обнуляет скругление своих элементов (`square.js`). Скругления Herdr остаются у его собственных окон: меню, диалогов, уведомлений, окна Settings.

Отступы сведены к одной сетке. Снаружи карточек 8: края полосы вкладок, поля и промежуток между терминалом и панелью. Полоса вкладок и строка с логотипом 42, кнопки в ней 26. Шапки карточек 32, и у терминала, и у панелей, поэтому их нижние линии идут на одной высоте. Внутри карточек отступ 14: у шапок, у текста терминала (`terminal_padding`) и у списков панелей. Кнопки в шапках 24, с подписью отступ 8. Ради отступа шапки терминала мод Herdr `pane` склонирован в `workbench-pane`. Сайдбар держит свой отступ 16 (8 поля и 8 строки), как у Herdr. Окна настроек и диалоги модов не трогались.

Базовая ветка для Review и Graph задана в `layouts/workbench.json` (`"base": "dev"`). Для другого проекта поменяй её там. Если у ветки своя база, её можно записать в git config: `git config branch.<ветка>.base master`. Тогда Review сравнивает ветку с ней, а Graph выделяет её. Если такой ветки нет ни локально, ни на origin, панели берут общую базу из раскладки.

Боковую панель Herdr запоминает для каждого пространства. Новое пространство открывается с панелью из `"defaultPanel"` в раскладке (сейчас Review). Если её закрыть, в этом пространстве она так и останется закрытой.

## Что изменено у авторов

Подробно в `UPSTREAM.md` рядом с каждым модом: откуда взят, на каком коммите, под какой лицензией и что поменяно. Коротко:

- Ни одна панель не коммитит: поле коммита убрано из `better-changes` и `reviewer`, `git-graph` разрешает только Fetch.
- Панели не создают worktree и не запускают агентов: это убрано из `gitlab`, `reviewer` и `over9k`.
- `reviewer` пишет только агенту Claude Code из того же worktree и не печатает заблокированному агенту.
- Из `over9k` вырезаны handoff, «clear + recap», запись в настройки Claude Code, самообновление, чтение экранов терминалов и запросы к GitHub.
- Проверка обновлений `git-graph` выключена.

## Установка

Нужны Herdr.app 0.1.15 или новее, `jq`, `node`, `rsync`. Для панели GitLab нужен [glab](https://gitlab.com/gitlab-org/cli) с выполненным `glab auth login` на свой хост.

```sh
scripts/install.sh --dry-run   # что изменится
scripts/install.sh             # поставить
herdr-app do layout.switch --name workbench
```

Скрипт сначала прогоняет `herdr-app check` по модам репозитория: если хоть один не прошёл, он ничего не ставит. Потом копирует моды в `~/.config/herdr-app/mods`, раскладку в `layouts/` и добавляет клавиши в `keys.json`. Перед этим он кладёт прежние версии этих файлов в `~/.local/share/herdr-app-backups/<время>`. Занятую клавишу он не заменяет, а печатает в отчёт. Моды Herdr остаются нетронутыми, и шаблонная раскладка `main` тоже.

После правки `keys.json` Herdr считает файл своим и новые клавиши из обновлений Herdr больше не подставляет: их добавляют руками.

## Клавиши

В раскладке `workbench`:

| Клавиша | Что делает |
| --- | --- |
| `cmd-alt-1` … `cmd-alt-5` | открыть или закрыть Files, Changes, Review, GitLab, Graph |
| `ctrl-tab` | переключатель агентов over9k |
| `cmd-shift-x` | закрыть терминал в табе, с подтверждением over9k для работающего агента |
| `cmd-alt-,` | настройки over9k |

## Откат

`ctrl-shift-l` или `herdr-app do layout.switch --name main` возвращает шаблонную раскладку. Удалить всё: папки модов из `mods/` этого репозитория в `~/.config/herdr-app/mods`, файл `layouts/workbench.json` там же и секции `layout:workbench` и `mod:over9k-switcher` из `keys.json`. Прежние файлы лежат в резервной копии.

## Обновление мода от автора

В `UPSTREAM.md` записан коммит, с которого взята копия. Первый коммит этого репозитория хранит копии без правок, поэтому свежую версию автора можно сравнить с ним и перенести наши правки по диффу.

## Лицензии

Каждый мод несёт лицензию автора в своей папке: MIT у `git-graph`, `gitlab`, `reviewer` и `over9k*`, Apache-2.0 у `better-files`, `better-changes`, `machine-vitals`, `workbench-tabs` и `workbench-pane` (клоны модов Herdr). Скрипты, раскладка и клавиши этого репозитория под MIT, текст в `LICENSE`.
