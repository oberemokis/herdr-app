# herdr-app

Моя настройка [Herdr.app](https://herdr.dev) под работу с агентами в git worktree: раскладка `workbench` и моды для неё. Моды взяты у авторов из галереи herdr.dev, лежат здесь копиями и подогнаны под один принцип: панели смотрят, а репозиторий меняет агент.

## Что в раскладке

| Где | Мод | Что показывает |
| --- | --- | --- |
| слева, первая строка | `workbench-brand` | пустая полоса, за которую тянут окно, и кнопка, которая сворачивает сайдбар в узкую полосу и разворачивает обратно |
| слева | `over9k` и его спутники | пространства и агенты: модель, контекст, кеш, сабагенты, фоновые задачи; задачи `task-fleet` деревом под пространством оркестратора |
| вкладки | `workbench-tabs` | вкладки, за ними «+» нового терминала, агента или worktree в текущем пространстве, справа кнопки боковых панелей |
| футер под терминалами, слева | `provider-limits` | расход лимитов подписок Claude и Codex по окнам (5 часов, неделя) с временем сброса; опрос раз в 5 минут, клик по провайдеру обновляет только его. Claude берётся по OAuth-токену Claude Code из связки ключей macOS, Codex через `codex app-server`; нужен `python3` |
| футер под терминалами, справа | `machine-vitals` | CPU со спарклайном и RAM в одну строку, подробности в подсказке; по клику окно монитора с историей за час и процессами Herdr |
| шапка терминала | `workbench-pane` | программа, папка и статус агента; кнопки разделить, развернуть, закрыть |
| панель Files | `better-files` | дерево файлов и просмотр |
| панель Git, вид Review | `reviewer` | дифф ветки от базы, рабочих изменений или коммита с комментариями по строкам, которые уходят агенту этого worktree |
| панель Git, вид Graph | `git-graph` | граф веток, база выделена; клик по коммиту открывает его в Review |
| вкладка с диффом | `better-changes` | файл из Review диффом во вкладке рядом с терминалами |
| панель Remote | `gitlab` или `github` | MR или PR ветки с пайплайном или проверками, списки MR или PR, задач и пайплайнов с подгрузкой страницами, логи джоб |
| панель Ports | `ports` | слушающие TCP-порты, сгруппированные по worktree, compose-папке или папке процесса; текущий worktree первым, конфликты одного порта, поиск с проверкой «порт свободен» и ближайшим свободным; открыть в браузере, скопировать, остановить процесс или контейнер |

Подвала с Settings и Add machine в сайдбаре нет: настройки Herdr открывает `cmd-,`, настройки over9k `cmd-alt-,`, машины добавляются в Settings → Machines.

Свёрнутый сайдбар (76 в macOS) показывает пространства плитками по центру: одна-две буквы имени (у задачи номер из имени ветки) в цвете проекта, точка самого срочного агента в углу, полное имя при наведении. Задачи `task-fleet` идут плитками поменьше под оркестратором, агентов и терминалов на полосе нет.

Тема `opencode` (тёмная) и `opencode-light` (светлая) в `themes/`: палитра темы по умолчанию из [OpenCode](https://github.com/anomalyco/opencode) (`packages/tui/src/theme/assets/opencode.json`, MIT), разложенная по цветам Herdr. Раскладка берёт ту, что соответствует режиму системы. Выбор в меню тем Herdr её перекрывает.

Углы везде прямые: у карточек терминалов радиус 0 в раскладке, а каждый мод при старте обнуляет скругление своих элементов (`square.js`). Скругления Herdr остаются у его собственных окон: меню, диалогов, уведомлений, окна Settings. Исключение внутри модов одно: статусы и метки (точки статуса, чипы над агентами, «Needs you», метки веток в графе, метки задач, счётчики) круглые, они рисуются через `rounded_full`, который `square.js` не трогает. Метки задач не берут цвет у GitLab и GitHub: пилюля в цветах темы, а свой цвет метки остаётся точкой, сведённой к ближайшему цвету темы.

Отступы сведены к одной сетке. Снаружи карточек 8: края полосы вкладок, поля и промежуток между терминалом и панелью. Полоса вкладок и строка с логотипом 42, кнопки в ней 26. Шапки карточек 32, и у терминала, и у панелей, поэтому их нижние линии идут на одной высоте. Внутри карточек отступ 14: у шапок, у текста терминала (`terminal_padding`) и у списков панелей. Кнопки в шапках 24, с подписью отступ 8. Ради отступа шапки терминала мод Herdr `pane` склонирован в `workbench-pane`. Сайдбар держит свой отступ 16 (8 поля и 8 строки), как у Herdr. Окна настроек и диалоги модов не трогались.

Базовая ветка для Review и Graph задана в `layouts/workbench.json` (`"base": "dev"`). Для другого проекта поменяй её там. Если у ветки своя база, её можно записать в git config: `git config branch.<ветка>.base master`. Тогда Review сравнивает ветку с ней, а Graph выделяет её. Если такой ветки нет ни локально, ни на origin, панели берут общую базу из раскладки.

Боковую панель Herdr запоминает для каждого пространства. Новое пространство открывается с панелью из `"defaultPanel"` в раскладке (сейчас Git). Если её закрыть, в этом пространстве она так и останется закрытой. Вид панели Git (Review или Graph) тоже запоминается для каждого пространства.

Панель Remote держит стопкой оба мода, `gitlab` и `github`, а видно тот, который знает remote репозитория в фокусе: если открыт не тот, он сам переключает стопку на соседа. Внутри подвкладки Branch, MRs или PRs, Issues, Pipelines или Runs, у списков фильтр по состоянию (открытые, слитые, закрытые, все). Список грузится по 20 строк: пока он короче окна, следующие страницы подгружаются сами, дальше по строке «Load more». Обновление по таймеру перечитывает загруженные страницы, но не больше пяти, и место прокрутки не сбивает. Подвкладка запоминается для каждого пространства, фильтр общий.

## Что изменено у авторов

Подробно в `UPSTREAM.md` рядом с каждым модом: откуда взят, на каком коммите, под какой лицензией и что поменяно. Коротко:

- Ни одна панель не коммитит: поле коммита убрано из `better-changes` и `reviewer`, `git-graph` разрешает только Fetch.
- Панели не создают worktree и не запускают агентов: это убрано из `gitlab`, `reviewer` и `over9k`, и в `github` этого нет.
- `github` своего автора не имеет: это порт `gitlab` на `gh`, чем он отличается, записано в его `UPSTREAM.md`.
- `reviewer` пишет только агенту Claude Code из того же worktree и не печатает заблокированному агенту.
- Из `over9k` вырезаны handoff, «clear + recap», запись в настройки Claude Code, самообновление, чтение экранов терминалов и запросы к GitHub.
- Проверка обновлений `git-graph` выключена.

## Установка

Нужны Herdr.app 0.1.15 или новее, `jq`, `node`, `rsync`. Для репозиториев GitLab в панели Remote нужен [glab](https://gitlab.com/gitlab-org/cli) с выполненным `glab auth login` на свой хост, для GitHub нужен [gh](https://cli.github.com) с выполненным `gh auth login`.

```sh
scripts/install.sh --dry-run   # что изменится
scripts/install.sh             # поставить
herdr-app do layout.switch --name workbench
```

Скрипт сначала прогоняет `herdr-app check` по модам репозитория: если хоть один не прошёл, он ничего не ставит. Потом копирует моды в `~/.config/herdr-app/mods`, раскладку в `layouts/` и добавляет клавиши в `keys.json`. Перед этим он кладёт прежние версии этих файлов в `~/.local/share/herdr-app-backups/<время>`. Занятую клавишу он не заменяет, а печатает в отчёт. Моды Herdr остаются нетронутыми, и шаблонная раскладка `main` тоже.

После правки `keys.json` Herdr считает файл своим и новые клавиши из обновлений Herdr больше не подставляет: их добавляют руками.

## Клавиши

В раскладке `workbench`:

| Клавиша | Что делает |
| --- | --- |
| `cmd-alt-1` | открыть или закрыть Files |
| `cmd-alt-2`, `cmd-alt-3` | Git на виде Review: рабочие изменения или ветка от базы; повторное нажатие закрывает |
| `cmd-alt-5` | Git на виде Graph |
| `cmd-alt-4`, `cmd-alt-6` | открыть или закрыть Remote (прежние клавиши GitLab и GitHub) |
| `cmd-alt-7` | открыть или закрыть Ports |
| `ctrl-tab` | переключатель агентов over9k |
| `cmd-shift-x` | закрыть терминал в табе, с подтверждением over9k для работающего агента |
| `cmd-alt-,` | настройки over9k |

## Откат

`ctrl-shift-l` или `herdr-app do layout.switch --name main` возвращает шаблонную раскладку. Удалить всё: папки модов из `mods/` этого репозитория в `~/.config/herdr-app/mods`, файл `layouts/workbench.json` там же и секции `layout:workbench` и `mod:over9k-switcher` из `keys.json`. Прежние файлы лежат в резервной копии.

## Проверка

Списки панели Remote проверяются на живых хостах, только чтением: страницы, курсоры, фильтр, отсутствие повторов, плюс разбор на фиксированных данных.

```sh
node --import ./scripts/test/hooks.mjs scripts/test/remote-pages.mjs
REMOTE_TEST_GITLAB=<хост>/<группа>/<проект> node --import ./scripts/test/hooks.mjs scripts/test/remote-pages.mjs
```

Без `REMOTE_TEST_GITLAB` часть про GitLab пропускается. GitHub по умолчанию читает `cli/cli`, другой репозиторий задаёт `REMOTE_TEST_GITHUB=<владелец>/<имя>`.

## Обновление мода от автора

В `UPSTREAM.md` записан коммит, с которого взята копия. Первый коммит этого репозитория хранит копии без правок, поэтому свежую версию автора можно сравнить с ним и перенести наши правки по диффу.

## Лицензии

Каждый мод несёт лицензию автора в своей папке: MIT у `git-graph`, `gitlab`, `github` (лицензия `gitlab`, от которого он портирован), `reviewer` и `over9k*`, Apache-2.0 у `better-files`, `better-changes`, `machine-vitals`, `workbench-tabs` и `workbench-pane` (клоны модов Herdr). Свой мод `ports`, скрипты, раскладка и клавиши этого репозитория под MIT (иконки Lucide в `ports` под ISC, текст в `LICENSE-lucide`), текст в `LICENSE`.
